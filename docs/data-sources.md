# データソースと設計

沖縄県知事選挙（第1回 1972年〜第15回 2026年）の得票と投票率。県全体は全回、市町村別は資料が手に入った回（第9〜15回）だけを持つ。

## 流れ

```
data/raw/{pref}/           取得元の原本（追跡しない。npm run fetch で再取得）
data/manual/{pref}/        手起こしの正本（追跡する。スクリプトは上書きしない）
  prefecture.json          県全体の投票結果・候補者・得票
  camps.json               候補者の陣営と、その根拠・出典
data/lineage/{pref}.json   合併の対応表（旧コード → 後継コード）
data/geo/{pref}/           市町村境界の TopoJSON（版ごと）
data/normalized/{pref}/    回ごとの正規化 JSON（npm run normalize が書く）
public/data/{pref}/        配信用 JSON（npm run data が書く）
```

`npm run verify` は正規化 JSON を検査し、1件でも落ちたら終了コード 1 を返す。

### 注意

- 第9〜12回（2002〜2014年）の市町村別は、県選管の旧サイト（`pref.okinawa.jp/site/senkan_i/`、2020年ごろ閉鎖）の資料を Internet Archive の保存版から取る。URL は保存時刻つき（`/web/{時刻}id_/`）で、保存版そのものを指す。県合計は年報・総務省と一致することを verify で確かめている。
- 2026年の特設ページには途中経過の開票速報 PDF も並んでいる。使うのは「開票確定」「投票確定」の訂正版だけ。
- 開票表の得票は按分票を含むことがあるので、小数のまま持つ。
- 第15回の職業は一次資料で確認できていないので `null`。
- 第13回の投票者数の男女内訳は、年報（345,079 / 380,175）と総務省（345,083 / 380,171）で4人ずれる。計（725,254）は同じ。年報の値を使い、verify は注意として出す。

## 検証（scripts/verify.ts）

- 各回: 男女の和が計に一致する、当選者が1人で最多得票
- 市町村別: 市町村が目録と揃う、得票の合計が有効投票に一致する、市町村の合計が県全体（候補者の得票・有権者数・投票者数の計）に一致する
- 市町村の顔ぶれ: その日に存在した市町村（合併の対応表から導く `municipalitiesAt`）と一致する
- 総務省（第11〜14回）: 有権者数・投票者数の計、候補者の得票、有効投票・無効投票の合計
- 那覇市（第1〜14回）: 候補者ごとの県全体得票と、市町村別がある回（第9〜14回）の那覇市の得票
- 陣営: 全候補者に割り当てがあり、上位2人が同じ陣営でない
- 地図: 市町村別の各回で、全市町村のコードが境界データにある
- 合併: 後継をたどると現行の市町村に着く、各回の市町村コードがその日に存在した

## 陣営の分類

`data/manual/47/camps.json` は編集上の判断。主要候補を、自民党など保守政党の推薦・支持を受けた「保守系」と、革新共闘会議や社会・共産・社大などの推薦・支持を受けた「革新系」に分け、どちらにも属さない候補は「その他」とする。

- 根拠は年報の党派欄（「革新共斗会議」「知事選革新共闘会議」など）を優先し、なければ各回の Wikipedia 記事の推薦・支持欄による。候補者ごとに根拠と出典 URL を持つ。
- 2014年の翁長雄志は保守出身だが、共産・社民・社大などが支持した「オール沖縄」の候補なので、革新系の流れに置く。
- 2002年は革新系が吉元政矩（社民・社大）と新垣繁信（共産）に割れたので、両者とも革新系。

## 市町村の持ち方

- 市町村別の結果は、その選挙の時点の市町村コードで持つ。その日に存在した市町村は、現行の41市町村と合併の対応表（`data/lineage/47.json`、e-Stat 統計LOD）から導く。
- 地図の版は選挙の日付で決まる（`src/lib/data/boundaries.ts` の `boundaryFor`）。いまは 2002年4月〜2005年3月の52市町村（`data/geo/47/2002.topojson`、第9回）と、2006年1月以降の41市町村（`data/geo/47/2006.topojson`、第10回以降）の2版。どちらも属性は国土数値情報 N03 と同じ `N03_007`（コード）・`nam_ja`（名前）。2002年版は2000年ごろの海岸線で、埋め立ての進んだ市町村（与那原町・豊見城市・那覇市など）は現行より面積が小さい。その日の版がない回は `boundary: null` になり、アプリは地図の代わりに一覧と推移だけを出す。
- 市町村ごとの推移と一覧は、合併の対応表で旧コードを現行コードに寄せ、得票を合算して描く。
- 地図では、遠く離れた無人島（硫黄鳥島・尖閣諸島・沖大東島）を枠の範囲外として描かず、注記する。

### 取り込み手順

1. 旧境界の TopoJSON を `data/geo/47/{版}.topojson` に置き、`src/lib/data/boundaries.ts` に版（有効になった日、コードと名前の属性名）を足す。`npm run verify` が、その回の全市町村のコードが地図にあるかを確かめる。
2. 紙の結果調を起こした市町村別の値を原本として置き（`data/raw/` に置く場合は `src/lib/data/sources.ts` に目録を足す）、`data/manual/47/prefecture.json` の該当回に `ballot` と `municipalities` を足す。その回の市町村の顔ぶれは合併の対応表から自動で決まる。
3. `npm run normalize && npm run verify && npm run data`。市町村の合計が年報の県全体と一致しなければ verify が落ちる。
